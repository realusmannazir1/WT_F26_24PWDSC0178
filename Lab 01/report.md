# Lab 01 Report – Git & Development Environment Setup

## Reflection

In this lab, I learned how to set up a complete web development environment using Visual Studio Code and Git. I configured Git with my identity and connected a local repository to a remote GitHub repository using HTTPS. Working with branches helped me understand how parallel development works — I created an `experiment` branch, made changes, and merged them back into `main`. Managing files through Git (adding, committing, deleting, and pushing) gave me a clear picture of how version control tracks every change in a project. Overall, this lab gave me a strong foundation in Git workflows that I will use throughout the course.

## Commands Used

| Command | Purpose |
|---|---|
| `git init` | Initialize a local repository |
| `git add` | Stage changes |
| `git commit` | Save a snapshot |
| `git push` | Upload to GitHub |
| `git pull` | Fetch and merge remote changes |
| `git branch` | Create/list branches |
| `git checkout` | Switch branches |
| `git merge` | Merge branches |
| `git clone` | Clone a remote repository |
