# Lab 01 Reflection

In this lab, I learned the basic commands of Git and GitHub. I learned how to create, modify, and delete files and track changes using Git. I also learned how to create branches and merge them into the main branch. This lab helped me understand how Git can be used to manage and collaborate on projects.

---

## Task Completion

### Task 1 – Creating an HTML File
Created `index.html` inside the Lab 01 folder with a basic HTML structure containing `<h1>Welcome to 224 Web Technologies Course</h1>`. Committed with message: *"Added index.html with welcome message"* and pushed to GitHub.

### Task 2 – Updating the HTML File with Comments
Added an HTML comment `<!-- This is my first HTML page for Lab 01 -->` above the heading in `index.html`. Committed with message: *"Updated index.html with HTML comment"* and pushed.

### Task 3 – Creating a .gitignore File
Created `.gitignore` inside Lab 01 folder specifying `*.log` and `temp/` to be ignored by Git. Committed with message: *"Added .gitignore file"* and pushed.

### Task 4 – Adding a License File
Created `LICENSE` file in the project root with the statement: *"This project is for educational purposes only."* Committed with message: *"Added LICENSE file"* and pushed.

### Task 5 – Creating and Deleting a File
Created `test.txt` with sample text and committed it. Then deleted the file, committed the deletion, and pushed both changes to demonstrate file tracking and removal in Git.

### Task 6 – Working with Branches
Created a new branch called `experiment` and switched to it. Added `<h2>This is an experimental change</h2>` to `index.html`. Committed the change and pushed the branch to GitHub.

### Task 7 – Merging Branches
Switched back to the `main` branch and merged the `experiment` branch into it. Pushed the updated `main` branch to GitHub.

### Task 8 – Writing a Markdown Report
Created `report.md` with a reflection on the lab experience covering Git commands, file management, and branching. Committed and pushed to GitHub.

### Task 9 – Adding Screenshots
Took screenshots showing Git terminal and VS Code setup. Created a `screenshots/` folder inside Lab 01, added all screenshots, committed and pushed to GitHub.

### Task 10 – Cloning the Repository
Cloned the GitHub repository into a new local folder to verify remote repository integrity. Took a screenshot of the cloned folder structure and pushed it to the `screenshots/` folder.
