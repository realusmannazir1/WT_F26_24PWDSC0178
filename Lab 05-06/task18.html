Media Preference Queries

This page automatically adapts to your system settings — dark mode, reduced motion, and orientation.

🌙
prefers-color-scheme

Dark Mode Support

This page detects your operating system's color scheme preference. If your system is set to dark mode, the entire page switches to a dark theme automatically — background, text, cards, and borders all change using CSS custom properties (variables).

Try switching your OS between light and dark mode to see the effect in real time.

⚡

Reduced Motion

If you have enabled "Reduce Motion" in your OS accessibility settings, all CSS transitions and animations are disabled on this page.

@media (prefers-reduced-motion: reduce)
📱

Orientation

The layout adjusts based on whether your device is in portrait or landscape orientation. The grid changes from 2 columns to 1 in portrait mode.

@media (orientation: portrait)
🖨

Print Media

When you print this page (Ctrl+P), a clean white print-friendly version is applied, removing dark backgrounds and shadows.

@media print
🎨

CSS Variables

All colors are defined as CSS custom properties in :root. The dark mode query simply overrides these variables — no duplicate CSS needed.

:root { --bg: #fff; }
