Responsive Utility Classes

A library of reusable CSS utility classes — resize to see responsive ones activate

Display Utilities

.d-none .d-block .d-flex .d-grid .d-inline .d-inline-block .d-md-block .d-lg-grid .mobile-hidden
.d-flex — This container uses flexbox
.mobile-hidden — Hidden on mobile (<768px)
.mobile-only — Visible only on mobile

Spacing Utilities

.p-1.p-2.p-3 .m-1.m-2 .mb-1.mb-2 .gap-1.gap-2
.p-1 — 10px padding
.p-2 — 20px padding
.p-3 — 30px padding

Typography Utilities

.text-center.text-sm .text-lg.text-xl .font-bold.text-muted.text-accent

.text-sm .text-muted — Small muted text

.text-lg .font-bold — Large bold text

.text-xl .text-accent — Extra large accent
